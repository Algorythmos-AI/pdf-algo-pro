# PDF Algo Pro

Welcome. PDF Algo Pro is a native PDF reader, editor and scanner for iPhone and iPad, and later Mac,
whose document intelligence (summaries, answers with page citations, data extraction) runs on the
device first. This wiki is institutional memory: short pages that explain and point to the
canonical documents in the repository. The repository's `docs/` folder is the source of truth, and
this wiki is regenerated from it on every release.
