# Security

Documents are the most sensitive data the app handles, and they stay on the device unless the user
opts in to a cloud tier. There are no third-party analytics, advertising or crash SDKs.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on the repository, or email info@algorythmos.com.au
with the subject `SECURITY: pdf-algo-pro`. Please do not open a public issue. See the
[security policy](../../.github/SECURITY.md).
