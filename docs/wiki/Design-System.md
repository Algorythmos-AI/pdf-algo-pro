# Design System

Native Apple design: system materials, SF Symbols, SF Pro through Dynamic Type, semantic colours
with the Algorythmos brand as an accent, an 8-point spacing grid, one motion helper that respects
Reduce Motion, and accessibility built in (VoiceOver, Voice Control, contrast at least WCAG AA).
