# Roadmap

Phases are outcomes, not dates: Foundation → MVP (iPhone, internal TestFlight) → V1 (App Store) →
V1.1 → V2 (iPad-first, Mac, the opt-in Claude tier at general availability) → later visionOS.
Platform priority is fixed: iPhone, iPad, Mac, then Apple Vision Pro.

GitHub milestones carry the same names, and the backlog is kept as code in
[backlog.yaml](../planning/backlog.yaml).
