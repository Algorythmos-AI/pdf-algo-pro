# Release Notes

Release notes are generated from the repository's [CHANGELOG](../../CHANGELOG.md) when a version is
tagged; each release adds a section here.

How release notes are written for each audience (CHANGELOG, TestFlight, App Store, this wiki) is in
the [changelog strategy](../changelog-strategy.md); the release process is in
[release management](../release-management.md).

## 1.0.0 - YYYY-MM-DD

The first App Store release of PDF Algo Pro, for iPhone. It reads, marks up, signs, scans, merges and
protects PDFs, and answers questions about a document with the pages cited, using Apple Intelligence
on the device; documents, questions and answers stay on the iPhone, and there is no account.
Editing the existing text of a PDF stays in TestFlight builds until its device test is signed off. The full list of changes and the
known issues are in the [GitHub Release for v1.0.0](https://github.com/Algorythmos-AI/pdf-algo-pro/releases/tag/v1.0.0)
and the [CHANGELOG](../../CHANGELOG.md).
